# Frontend TypeScript/React Rules

## Routing
- Route files live at `frontend/src/routes/_layout/<name>.tsx`
- `createFileRoute("/_layout/<name>")` path must match the filename exactly
- Never edit `.tanstack/routeTree.gen.ts` — it's auto-generated by the Vite plugin on `bun run dev`
- Auth is enforced by `_layout.tsx` `beforeLoad` — no extra auth check needed in page files

## Data fetching
- Use `useSuspenseQuery` for data in page components
- Extract query options into `get<Name>QueryOptions()` functions
- Always wrap data-fetching components in `<Suspense fallback={<Skeleton />}>`
- Never use raw `fetch` or `axios` directly — import from `@/client` only

## API client
- Client lives in `frontend/src/client/` — auto-generated, do not edit
- Regenerate after any backend route/model change: `bash scripts/generate-client.sh` from repo root
- `OpenAPI.TOKEN` is set from localStorage — never hardcode tokens

## Forms
- `react-hook-form` + `zod` validation schema
- ShadcnUI `<Form>`, `<FormField>`, `<FormItem>`, `<FormControl>` for all form fields
- `useMutation` from `@tanstack/react-query` for writes
- `useCustomToast` from `@/hooks/useCustomToast` for success/error notifications

## Styling
- Tailwind utility classes only — no inline styles
- Use semantic tokens: `bg-background`, `text-foreground`, `text-muted-foreground` — not hardcoded colors
- ShadcnUI components live in `frontend/src/components/ui/`

## New pages
- Add a sidebar entry to `baseItems` in `frontend/src/components/Sidebar/AppSidebar.tsx`
- Create a skeleton component in `frontend/src/components/Pending/Pending<Name>.tsx`

## Linting
- Biome handles both linting and formatting: `bun run lint`
- TypeScript: `bunx tsc --noEmit`
