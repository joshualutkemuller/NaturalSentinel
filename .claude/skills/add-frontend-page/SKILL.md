Scaffold a new authenticated frontend page.

Page name and route path: $ARGUMENTS
(e.g., `Filings /filings`)

## Step 1 — Read the reference

Read `frontend/src/routes/_layout/items.tsx` and `frontend/src/components/Sidebar/AppSidebar.tsx` before writing anything.

## Step 2 — Regenerate client (if endpoint is new)

If the backend route for this page is new, run `/generate-client` first.

## Step 3 — Create the route file

Create `frontend/src/routes/_layout/<route>.tsx`:

```tsx
import { useSuspenseQuery } from "@tanstack/react-query"
import { createFileRoute } from "@tanstack/react-router"
import { Suspense } from "react"

import { <Tag>Service } from "@/client"
import Pending<Name> from "@/components/Pending/Pending<Name>"

function get<Name>QueryOptions() {
  return {
    queryFn: () => <Tag>Service.list<Name>(),
    queryKey: ["<camelName>"],
  }
}

export const Route = createFileRoute("/_layout/<route>")({
  component: <Name>,
  head: () => ({
    meta: [{ title: "<Page Title> - NaturalSentinel" }],
  }),
})

function <Name>Content() {
  const { data } = useSuspenseQuery(get<Name>QueryOptions())
  return (
    <div className="container mx-auto py-6">
      {/* content */}
    </div>
  )
}

function <Name>() {
  return (
    <div className="flex flex-col gap-6">
      <div className="flex items-center justify-between">
        <h1 className="text-2xl font-bold"><Page Title></h1>
      </div>
      <Suspense fallback={<Pending<Name> />}>
        <<Name>Content />
      </Suspense>
    </div>
  )
}
```

**Rules:**
- Always wrap data-fetching in `<Suspense>` with a skeleton fallback
- Auth is enforced by `_layout.tsx` `beforeLoad` — no extra auth check needed
- NEVER edit `.tanstack/routeTree.gen.ts` — it's auto-generated by the Vite plugin
- Import from `@/client` only — never raw `fetch`

## Step 4 — Add sidebar entry

Edit `frontend/src/components/Sidebar/AppSidebar.tsx`, add to `baseItems`:
```tsx
import { <LucideIcon> } from "lucide-react"

{ icon: <LucideIcon>, title: "<Label>", path: "/<route>" },
```

## Step 5 — Create skeleton component

Create `frontend/src/components/Pending/Pending<Name>.tsx` following `PendingItems.tsx` — a simple skeleton using ShadcnUI `<Skeleton>`.

## Step 6 — Forms (if needed)

For create/edit dialogs, follow `frontend/src/components/Items/AddItem.tsx`:
- `react-hook-form` + `zod` + ShadcnUI `<Form>`, `<FormField>`, `<FormItem>`, `<FormControl>`
- `useMutation` from `@tanstack/react-query`
- `useCustomToast` for success/error notifications

## Step 7 — Verify

```bash
cd frontend && bunx tsc --noEmit && bun run lint
```
